# Curated Project Ideas

Three beginner-friendly project ideas for the guided build. Present all three, then offer the custom option.

Each idea fits the constraints: frontend-only, Next.js + Tailwind, no database/auth/API, 3–4 features, buildable in ~20 minutes.

---

## 1. Personal Bookmark Saver

A clean, visual app for saving and organising your favourite links.

**Features:**
1. **Add bookmarks** — A form to add a bookmark with title, URL, and description
2. **Bookmark grid** — All bookmarks displayed in a responsive card grid
3. **Delete bookmarks** — Remove bookmarks you no longer need
4. **Search and filter** — Find bookmarks by title or description

**What it looks like when done:** A page with a form at the top and a grid of bookmark cards below. Each card shows the title, URL, and description with a delete button. A search bar filters the grid in real time.

**Why this is a good first project:** Immediate visual feedback — every action (add, delete, search) changes what you see. Simple data model (title, URL, description). Satisfying card layout.

---

## 2. Daily Quote Board

A colourful board for collecting and displaying your favourite quotes.

**Features:**
1. **Add quotes** — A form to add a quote with text and author
2. **Featured quote** — A large, highlighted random quote at the top
3. **Quote wall** — All quotes displayed in a masonry-style grid
4. **Favourite quotes** — Mark quotes as favourites and filter to see only favourites

**What it looks like when done:** A hero section with one large quote, then a grid of smaller quote cards below. Each card has the quote text, author, and a heart icon to favourite. A toggle shows all quotes or just favourites.

**Why this is a good first project:** Very visual — the featured quote changes each visit. The favourite toggle teaches interactive state. The masonry grid looks impressive with minimal effort.

---

## 3. Mini Portfolio

A personal portfolio page you can actually keep and share.

**Features:**
1. **Hero section** — Your name, a one-line bio, and a profile area
2. **Project cards** — 3 project cards with title, description, and a link
3. **Skills section** — A visual display of your skills or interests
4. **Contact section** — Links to your email, GitHub, or social profiles

**What it looks like when done:** A single-page portfolio with a hero at the top, a grid of project cards in the middle, a skills section, and contact links at the bottom. Clean, modern, responsive.

**Why this is a good first project:** Real content the participant can keep. Teaches layout and component composition. Looks professional with Tailwind's defaults. Can be deployed later as an actual portfolio.

---

## Custom option

If none of these appeal, the participant can bring their own idea. Apply the same constraints:
- Frontend-only (Next.js + Tailwind)
- 3–5 features that produce visible browser results
- No database, no auth, no external APIs
- Buildable in ~20 minutes

Help them scope it. If their idea is too ambitious, suggest a simplified version and frame it positively: "You can build the full version in your afternoon track."
